计算公式说明
  • 同一间距 D 下先后两次测量：
    C1=C0+C边+C分,C2=C串+C边+C分
  • 其中样品面积 S 的空气电容与介质层、空气层串联电容：
    C0=ε0SD,C串=ε0S(D−t+tεr)
  • 两次相减消去 C边 与 C分：
    C串=C2−C1+C0
  • 固体相对介电常数（逐行计算，再取三次平均）：
    εr=tC串ε0S−(D−t)C串
  • 固体数据的线性检验（最小二乘）：
    1C串=a+bD,b=1ε0S,a=−t(1−1εr)b
  • 空气数据的统计计算法（Y = A＋BX，X = 1/D）：
    C=C分+ε0S01D,ε0=BS0
  • 两次测量：C₁ = C₀＋C边＋C分（空气）；C₂ = C串＋C边＋C分（放入样品）。同一间距 D 下 C边、C分 不变。
  • C₀ = ε₀S/D 为样品面积 S 的空气电容；C串 = ε₀S/(D−t＋t/εᵣ) 为介质层与空气层串联的电容。
  • 两次相减消去 C边、C分：C串 = C₂−C₁＋C₀。
  • 固体相对介电常数：εᵣ = tC串/[ε₀S−(D−t)C串]，逐行计算后取三次平均。
  • 线性检验：1/C串 = a＋b·D，b = 1/(ε₀S) 反推面积，a = −t(1−1/εᵣ)b 给出 εᵣ = 1/(1＋a/(bt))。
  • 统计计算法：C = C分＋ε₀S₀/D 与 Y = A＋BX 对比（X = 1/D），A = C分，B = ε₀S₀，故 ε₀ = B/S₀。

两次测量必须保持同一极板间距 D 且系统状态不变，才能消去边界电容 C边 与分布电容 C分。样品直径用游标卡尺、厚度用螺旋测微器测量，电极直径由仪器标牌给出。不确定度至多保留两位有效数字（四舍六入五凑偶）。结果同时给出「X ± U」与新标准记法「X(U)」两种形式：U 小于 1 时括号内省略前导「0.」，如 8.86 ± 0.01 记作 8.86(1)；U 不小于 1 时括号内原样保留。
