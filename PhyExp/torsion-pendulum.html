计算公式说明
  • 扭转常数：
    K=4π2I1′T12−T02，I0=I1′T02T12−T02
  • 理论值：
    I1′=18m1D12， I2′=18m2(D外2+D内2)， I3′=110m3D直2， I4′=112m4L2
  • 实验值：
    I1=KT124π2−I0， I2=KT224π2−I0， I3=KT324π2， I4=KT424π2
  • 平行轴定理：
    I5′=2(116m(D外2+D内2)+112mL12)， I理=I4′+2mx2+I5′
  • 百分差：
    E=|I实−I理|I理×100%
  • K = 4π²·I1′/(T1² − T0²)，　I0 = I1′·T0²/(T1² − T0²)
  • 理论值：I1′ = (1/8)m1D1²；I2′ = (1/8)m2(D外² + D内²)；I3′ = (1/10)m3D直²；I4′ = (1/12)m4L²
  • 实验值：I1 = K·T1²/(4π²) − I0；I2 = K·T2²/(4π²) − I0；I3 = K·T3²/(4π²)；I4 = K·T4²/(4π²)
  • 平行轴定理：I5′ = 2[(1/16)m(D外² + D内²) + (1/12)m·L1²]；I理 = I4′ + 2m·x² + I5′
  • 百分差 E = |I实 − I理| / I理 × 100%

说明：圆筒与塑料圆柱是垂直装在载物盘上测量的，其实验值须扣除载物盘转动惯量 I0；木球、金属细杆是取下载物盘后直接装在转轴上，故不扣 I0。验证平行轴定理时，将两滑块对称置于金属细杆两边，滑块质心距转轴距离分别为 5.00、10.00、15.00、20.00、25.00 cm，各位置的理论值按平行轴定理计算。
