二、拟合结果

u(k)、u(b) 为斜率与截距的 A 类标准不确定度；r 为相关系数，|r| 越接近 1 说明线性越好。不确定度至多保留两位有效数字（四舍六入五凑偶），测量值末位与不确定度对齐；结果同时给出「X ± U」与新标准记法「X(U)」两种形式：U 小于 1 时括号内省略前导「0.」，如 0.149242 ± 0.00136 记作 0.14924 ± 0.0014，即 0.14924(14)、4.6170 ± 0.0006 记作 4.6170(6)；U 不小于 1 时括号内原样保留，如 3.1(1.2)。

计算公式说明
  • 拟合直线：
    k=n∑xiyi−∑xi∑yin∑xi2−(∑xi)2， b=y¯−kx¯
  • 相关系数：
    r=n∑xiyi−∑xi∑yi(n∑xi2−(∑xi)2)(n∑yi2−(∑yi)2)
  • 决定系数：
    R2=r2=(n∑xiyi−∑xi∑yi)2(n∑xi2−(∑xi)2)(n∑yi2−(∑yi)2)
  • 残差标准差：
    s=∑(yi−kxi−b)2n−2
  • A 类不确定度：
    u(k)=snn∑xi2−(∑xi)2
    u(b)=s∑xi2n∑xi2−(∑xi)2
  • 强制过原点时：
    k=∑xiyi∑xi2， u(k)=s1∑xi2（自由度取n−1）
  • 斜率 k = [ nΣxᵢyᵢ − Σxᵢ Σyᵢ ] / [ nΣxᵢ² − (Σxᵢ)² ]，截距 b = ȳ − k·x̄
  • 相关系数 r = [ nΣxᵢyᵢ − Σxᵢ Σyᵢ ] / √[ ( nΣxᵢ² − (Σxᵢ)² )( nΣyᵢ² − (Σyᵢ)² ) ]
  • 决定系数 R² = r² = [ nΣxᵢyᵢ − Σxᵢ Σyᵢ ]² / { ( nΣxᵢ² − (Σxᵢ)² )( nΣyᵢ² − (Σyᵢ)² ) }
  • 残差标准差 s = √{ Σ(yᵢ − k·xᵢ − b)² / (n − 2) }
  • u(k) = s·√[ n / (nΣxᵢ² − (Σxᵢ)²) ]；u(b) = s·√[ Σxᵢ² / (nΣxᵢ² − (Σxᵢ)²) ]
  • 强制过原点时：k = Σxᵢyᵢ / Σxᵢ²，u(k) = s·√(1/Σxᵢ²)，自由度取 n − 1
