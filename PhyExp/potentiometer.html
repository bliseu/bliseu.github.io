电位差计测量电动势

Potentiometer · Compensation Method

十一线电位差计：模拟接线 → 工作电流标准化（定标）→ 补偿法测干电池电动势，A 类＋B 类不确定度合成

一、连接电路（模拟接线）

按原理图把电位差计实验仪（左）与十一线电位差计板（右）连接起来：先点击一个接线柱，再点击另一个接线柱，即可连出一根导线。共 6 根：工作电流回路 2 根、补偿回路 2 根（C 插孔线与 D 刻度盘线）、待测干电池 2 根。接错的组合不会被接受，可按任意顺序连接。

已连接 0 / 6 根导线
  1. ○工作电源 E＋ → 电阻丝 A 端（工作电流回路）
  2. ○工作电源 E− → 电阻丝 B 端（工作电流回路）
  3. ○C 插孔引线 → 接线柱 C（补偿回路，经机内保护电阻 S₃ 与检流计）
  4. ○D 刻度盘引线 → 接线柱 D（补偿回路，经机内选择开关 S₂ 接 En 或 Ex）
  5. ○接线柱 Ex＋ → 干电池「＋」（待测电动势）
  6. ○接线柱 Ex− → 干电池「−」（待测电动势）

接线完成 ✓　通电前检查：① S₂ 拨到中间位置（断开补偿回路）；② S₃ 断开（检流计串入 10 kΩ 保护电阻）；③ 检流计档位置「断开」，调节调零旋钮使示值为零；④ 使用机内检流计与标准电势源（S₅、S₆ 向下合）。确认无误后合上电源总开关，到第二部分定标与测量。

二、工作电流标准化（定标）与测量

定标：选定校正系数 u₀，按 Ls = En/u₀ 把 C 插入相应插孔、刻度盘转到相应读数；S₂ 拨向 En，把电源电压 E₀ 预置到 11·u₀ 附近；由粗到细调节 E₀（配合逐步提高检流计灵敏度档位），直到 10⁻⁸ A 档示零，按「记录定标」。测量：估计 Lx = E估/u₀，重设插孔与刻度盘；S₂ 拨向 Ex，细调刻度盘到 10⁻⁸ A 档示零，按「记录测量」。每组测 5 次（电池电动势的微小变化会使示数再次偏离，需重新细调平衡）。

B 类不确定度来自刻度盘分辨率 ΔL = 0.001 m（Lx 与 Ls 各一项）；校正系数越小（电阻丝用得越长），u_B 与 U 越小，测量越精密。

计算公式说明
  • 补偿条件与工作电流标准化（定标，En = 1.0186 V）：
    u0·Ls=En,u0=EnLs=E0L(L=11m)
  • 测量（保持工作电流不变）：
    Ex=u0·Lx,Lx=n(C插孔)+D刻度盘读数
  • 平均值：
    E¯=1n∑i=1nEi
  • A 类不确定度：
    uA=sn,s=1n−1∑i=1n(Ei−E¯)2
  • B 类不确定度（刻度盘分辨率 ΔL = 0.001 m）：
    uB=Ex(ΔL/3Lx)+(ΔL/3Ls)
  • 合成不确定度与结果表达式：
    U=uA2+uB2,E=E¯±U,即E¯(U)
  • 定标（补偿条件）：u₀·Ls = En，u₀ = En/Ls = E₀/L（L = 11 m，Ls = En/u₀，如 u₀ = 0.2000 V/m 时 Ls = 5.093 m）。
  • 测量：Ex = u₀·Lx，Lx = C 插孔读数（整数米）＋ D 刻度盘读数（0—0.999 m）。
  • 平均值：Ē = (1/n)ΣEᵢ。
  • A 类不确定度：u_A = s/√n，s = √[Σ(Eᵢ−Ē)²/(n−1)]。
  • B 类不确定度：u_B = Ex·√[(ΔL/(√3·Lx))² ＋ (ΔL/(√3·Ls))²]，ΔL = 0.001 m。
  • 合成：U = √(u_A²＋u_B²)；结果 E = Ē ± U，即 Ē(U)。

补偿法的要点：检流计示零时测量回路电流为零，被测电动势不受测量装置分流影响。定标与测量之间必须保持工作电流不变（电源电压 E₀ 不动、电阻丝回路不断开）。B 类不确定度取刻度盘分辨率 ΔL = 0.001 m 按均匀分布处理；标准电池的影响远小于此项，已忽略。不确定度至多保留两位有效数字（四舍六入五凑偶），结果同时给出「X ± U」与新标准记法「X(U)」两种形式：U 小于 1 时括号内省略前导「0.」，如 1.5020 ± 0.0003 记作 1.5020(3)。
