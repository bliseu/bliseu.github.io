三、汞灯定标：最小二乘法求光栅常数 d

汞灯各已知谱线，转动望远镜分别对准 +1 级与 −1 级谱线记录读数，衍射角 φ = |θ₊₁ − θ₋₁| / 2。以 sinφ 对 λ 作过原点直线拟合（sinφ = λ/d，斜率 b = 1/d），由斜率求光栅常数 d = 1/b。

用上一步求出的光栅常数 d，测定氦灯各分立谱线的衍射角，由 λ = d·sinφ 计算波长，并与附表 6 参考值比较。

计算公式说明
  • 反射法测顶角：
    A=14[(θ左′−θ左)+(θ右′−θ右)]
  • 光栅方程：
    dsinθ=kλ，k=0,±1,±2,…
  • 衍射角（消除零级位置偏差）：
    φ=|θ+1−θ−1|2
  • 定标最小二乘：
    sinφ=λd，b=1d，d=1b
  • 氦灯波长：
    λ=dsinφ
  • 反射法测顶角：A = ¼[(θ′左 − θ左) + (θ′右 − θ右)]
  • 光栅方程：d·sinθ = k·λ，k = 0, ±1, ±2, …
  • 衍射角（消除零级位置偏差）：φ = |θ₊₁ − θ₋₁| / 2
  • 定标最小二乘：sinφ = λ/d，斜率 b = 1/d，d = 1/b
  • 氦灯波长：λ = d·sinφ

角游标分度值 1′，读数以「度°分′」记录（如 60°30′）。反射法测顶角时，平行光从顶角方向同时入射两个反射面，两面反射像对称分立，望远镜在两侧转过的角度为 2A，故 A = φ/2。光栅光谱中，同一波长 ±1 级衍射分立于零级两侧，取两侧读数差的一半作衍射角 φ 可消除零级位置与光栅法线不严格垂直于光轴引起的系统偏差。顶角结果同时给出「A = (60°00′ ± 0′)」与新标准记法「60°00′(0′)」两种形式，括号内为不确定度（角分）。
