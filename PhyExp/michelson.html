计算公式说明
  • 动镜位置读数：
    d=a+0.01b+0.00001c（mm）
  • 等倾干涉条纹：
    d 每改变 λ2，中心“冒出”或“消失”一个圆环；N 个环对应 Δd=Nλ2
  • 逐差法：
    Δd1=d3−d0，Δd2=d4−d1，Δd3=d5−d2
  • 逐差法波长：
    λ=2ΔdN，N=3×每步条纹数（Δd 为三对差值的平均）
  • 逐差法不确定度：
    uA=Σ(Δdi−Δd¯)2n(n−1)（n = 3），uB=23Δ3，u(Δd)=uA2+uB2
  • 最小二乘法：
    d=a+bk（k 为条纹数），λ=2b，r=Σ(ki−k¯)(di−d¯)Σ(ki−k¯)2Σ(di−d¯)2
  • 最小二乘法不确定度：
    uA(b)=snnΣk2−(Σk)2，s=Σ(di−a−bki)2n−2，uB(b)=Δ3Σ(ki−k¯)2
  • 动镜位置读数：d = a + 0.01·b + 0.00001·c（mm），a 主尺、b 粗调手轮、c 微调手轮（含估读位）
  • d 每改变 λ/2，中心“冒出”或“消失”一个圆环；N 个环对应 Δd = N·λ/2
  • 逐差法：Δd₁ = d₃ − d₀，Δd₂ = d₄ − d₁，Δd₃ = d₅ − d₂
  • 逐差法波长：λ = 2·Δd / N，N = 3 × 每步条纹数（Δd 为三对差值的平均）
  • 逐差法不确定度：u_A(Δd) = √[ Σ(Δdᵢ − Δd)² / (n(n−1)) ]（n = 3，即三对 Δd 的分散）；u_B(Δd) = √(2/3)·(Δ/√3)（Δ = 0.00001 mm，读数分辨力）；u(λ) = 2·u(Δd)/N
  • 最小二乘法：对 6 组 (k, d) 拟合 d = a + b·k（k 为条纹数），λ = 2b
  • 最小二乘法不确定度：u_A(b) = s·√[ n / (nΣk² − (Σk)²) ]，s = √[ Σ(dᵢ − a − b·kᵢ)² / (n − 2) ] 为残差标准差；u_B(b) = Δ / (√3·√Σ(kᵢ − k̄)²)；u(λ) = 2·u(b)

迈克耳孙干涉仪中，M₁ 的位置由三部分读出：主尺（整数 mm，一般两位）、粗调手轮读数窗（100 等分，0.01 mm/格）、微调手轮（100 等分，0.0001 mm/格，可估读到 0.00001 mm）。故动镜位置 d 有 5 位小数：d = a + 0.01b + 0.00001c，其中微调读数 c 为三位数，末位为估读位。He-Ne 激光标准波长 632.8 nm。B 类不确定度取读数分辨力 Δ = 0.00001 mm 按均匀分布处理（u_B = Δ/√3）；不确定度修约到两位有效数字（四舍六入五凑偶），测量值修约到与不确定度相同的末位，结果写成「X ± U，即 X(U)」两种记法。
