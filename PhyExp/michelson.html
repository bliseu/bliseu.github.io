计算公式说明
  • 动镜位置读数：
    d=a+0.01b+0.00001c（mm）
  • 等倾干涉条纹：
    d 每改变 λ2，中心“冒出”或“消失”一个圆环；N 个环对应 Δd=Nλ2
  • 逐差法：
    Δd1=d3−d0，Δd2=d4−d1，Δd3=d5−d2
  • 波长：
    λ=2ΔdN，N=300（Δd 为平均移动距离）
  • 动镜位置读数：d = a + 0.01·b + 0.00001·c（mm），a 主尺、b 粗调手轮、c 微调手轮（含估读位）
  • d 每改变 λ/2，中心“冒出”或“消失”一个圆环；N 个环对应 Δd = N·λ/2
  • 逐差法：Δd₁ = d₃ − d₀，Δd₂ = d₄ − d₁，Δd₃ = d₅ − d₂
  • 波长：λ = 2·Δd / N，N = 300（Δd 为平均移动距离）

迈克耳孙干涉仪中，M₁ 的位置由三部分读出：主尺（整数 mm，一般两位）、粗调手轮读数窗（100 等分，0.01 mm/格）、微调手轮（100 等分，0.0001 mm/格，可估读到 0.00001 mm）。故动镜位置 d 有 5 位小数：d = a + 0.01b + 0.00001c，其中微调读数 c 为三位数，末位为估读位。He-Ne 激光标准波长 632.8 nm。
